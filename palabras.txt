#  PALABRAS DEL RADAR DE CHOLLOS
#  Edita este archivo para decidir qué ofertas te llegan al grupo.
#  En GitHub: abre el archivo → icono del lápiz → cambia → "Commit changes".
#  El cambio se aplica en la siguiente ronda (≈10 min).
# ════════════════════════════════════════════════════════════════════
#
#  CÓMO SE ESCRIBE
#   [🎮 Nombre]       → empieza una categoría (el emoji es opcional)
#   palabra           → la oferta ENTRA si el título la contiene
#   -palabra          → la oferta NO entra si el título la contiene
#   +palabra          → la oferta entra SIEMPRE, aunque tenga una palabra con -
#   a, b, c           → puedes poner varias en una línea separadas por comas
#   apagada           → desactiva la categoría sin borrarla
#
#  OPCIONES DE CADA CATEGORÍA (opcionales; AHORA MISMO NO HAY NINGUNA PUESTA)
#   Sin opciones, todas las categorías usan el mínimo general de 200°
#   (config.json → grados_minimos) y no tienen límite de precio.
#   Si quieres alguna, escríbela debajo del [nombre] de la categoría, sin #:
#   grados: N         → mínimo de grados distinto para esa categoría
#   precio max: N     → solo ofertas hasta N €
#   precio min: N     → solo ofertas desde N €
#   tema: N           → manda los avisos a ese tema del grupo de Telegram
#   necesita: x, y    → además, el título tiene que llevar alguna de estas (sirve para dejar fuera juegos)
#   aviso: x, y => ⚠️ texto  → añade una nota al aviso si el título contiene x o y
#
#  TRUCOS
#   · Da igual mayúsculas y tildes: "portátil" = "PORTATIL".
#   · Busca palabras completas: "mando" no salta con "comando".
#   · Una línea que empieza por # es un comentario y se ignora.
#   · Avanzado: "re:" delante para una expresión regular (re:\brtx\s?50\d0\b).
#     Una expresión regular va SOLA en su línea (sin comas).
# ════════════════════════════════════════════════════════════════════
